# Security Policy

## Reporting a Vulnerability

Do not publish security issues publicly before maintainers have had time to triage them.

Send reports to:

- support@chat-stem.ru

Include:

- affected version;
- operating system;
- reproduction steps;
- expected and actual result;
- any logs or screenshots with tokens, cookies, passwords and private user data removed.

## Supported Scope

This repository covers the open-source desktop shell only. Server-side API, production infrastructure and private service configuration are outside this repository.

## Secrets

Do not commit signing keys, PFX files, updater private keys, certificates with private material, access tokens, cookies, production logs or user data.
